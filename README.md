# Web Bimbel Feryansyah Ariady

Website belajar pribadi berbasis link untuk siswa.

## Tahap 1
- Halaman beranda
- Pilih kelas 1–6
- Pilih mata pelajaran
- Menu Materi, Latihan, Ulangan, dan Hasil Belajar
- Tampilan responsif desktop/mobile
- Tanpa login
- Tanpa Gemini API
- Tanpa database

## Tahap berikutnya
1. Materi dan soal nyata
2. Sistem latihan/ulangan
3. Perhitungan nilai otomatis
4. Penyimpanan hasil siswa
5. Dashboard guru
6. Link belajar khusus siswa
7. Database persisten
